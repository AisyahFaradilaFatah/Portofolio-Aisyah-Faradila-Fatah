IDP Multi-Rekening System

Arsitektur data pipeline yang dirancang untuk mengekstrak, membersihkan, dan menstrukturkan data transaksi keuangan dari dokumen PDF mentah (rekening koran) secara otomatis.

💡 Technical Highlights:

  • Membangun End-to-End Data Pipeline untuk pemrosesan dokumen masif.
  • Menggunakan Automated Text Parsing (OCR) melalui skrip Python tingkat lanjut.
  • Melakukan Relational Data Structuring untuk diunggah otomatis ke basis data.
Tech Stack: Python, PHP, PostgreSQL, OCR. Outcome: Mengotomatiskan entri data manual menjadi format siap analisis.

Smart Monitoring Nutrition

Sistem terintegrasi berbasis Internet of Things (IoT) yang dirancang untuk memantau indikator kesehatan dan parameter nutrisi pengguna secara real-time dan nirkabel.

💡 Technical Highlights:

  • Membangun infrastruktur Real-time Data Transmission via cloud.
  • Mengembangkan model Machine Learning untuk prediksi level nutrisi dengan akurasi tinggi.
  • Mendesain antarmuka Interactive Mobile UI/UX untuk kemudahan pengguna.
Tech Stack: Python, Scikit-Learn, ESP32, Firebase, MQTT. Impact: Menghasilkan solusi kesehatan digital terpadu dengan integrasi hardware-software.
